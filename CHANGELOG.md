# Changelog

## 6.2.0 — 2026-10-23

- Fixed doubly scaled Canyon rocks and enforced clearance from the entire circuit; revised Canyon lighting and road contrast.
- Added optional automatic blaster fire, predictive target leading, elevation-aware shots, hill occlusion and cloaked-target exclusion.
- Added Rapid Fire, Plasma Rounds, Pickup Magnet and Ability Recharge, with distinct 3D pickup models, labels, effects and timed HUD indicators.
- Matched authoritative LAN aim, damage, cooldowns and power-ups to solo behavior.
- Fixed shared EMP cooldowns, separated oil/mine cooldowns, bounded mine lifetime, and throttled pickup requests and oil notifications.
- Improved muzzle flashes, tracer variants, hit feedback, particle scale and HUD readability.
- Added combat and Canyon regression coverage.

## 6.1.0 — 2026-10-22

- Corrected A/D and arrow steering from the driver's view; matched wheel animation and AI turns.
- Added phone tilt with explicit permission, calibration, sensitivity, inversion, optional auto-acceleration, stale-sensor protection and touch fallback.
- Added separate gas/brake pedals and in-race tilt settings. Braking overrides auto-acceleration.
- Removed desktop and LAN ZIP downloads. Desktop users launch the browser game; mobile users install the web app.
- Added static game, mobile, about and privacy guides, canonical/social metadata, JSON-LD, sitemap, robots.txt and optional llms.txt.
- Added content-hashed offline caching and explicit update activation.
- Added MIT license, dependency notices, GitHub CI, Dependabot, issue templates and contribution/security guidance.

## 6.0.0 — 2026-10-21

- Expanded the garage to six procedural 3D vehicles with a responsive website and improved game UI.
- Added graphics, weather, difficulty, audio and key settings.
- Improved fixed-step simulation, swept projectile collisions, pause timing, ordered checkpoints, race cleanup and bounded survival waves.
- Added optional 2–6 player LAN rooms with server-owned combat and race progress.
